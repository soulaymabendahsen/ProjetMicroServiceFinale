BookStore en ligne : Booky
________________


1. Présentation Générale du Projet
Le projet "Booky" est une librairie en ligne construite selon une architecture à base de microservices. Il repose sur diverses technologies telles que Spring Boot, Node.js, Keycloak, MongoDB, MySQL, etc. L'objectif principal est de gérer l'ensemble du cycle de vie des livres, paniers, utilisateurs, paiements et réclamations.
Chaque microservice est indépendant, enregistré dans Eureka Server, communique via Feign Clients ou via API Gateway.
________________


2. Architecture Globale
* Microservices Spring Boot (4 services, chacun avec sa propre base de données)
* Microservice Node.js (Service de réclamations)
* Keycloak : Authentification et gestion des rôles
* API Gateway : Entrée unique pour les appels REST
* Eureka Server : Découverte de services
* Config Server : Centralisation des configurations
* Frontend : Interface simple en Angular
* Docker : Conteneurisation de l'ensemble de l'application

4. Détails Techniques des Microservices
4.1 Service Cart
* Port : 8082
* Nom : Syrine Kaabi
* Base de données : MySQL 
* Fonctionnalités :
   * Ajouter / modifier / supprimer un article du panier
   * Rechercher par titre
   * Vider le panier
   * Statistiques de popularité (XChart)
   * QR Code généré pour chaque panier
* Endpoints REST : /cart/add, /cart/remove/{id}, /cart/chart/popularity, etc.
* Dépendances : Eureka, Config Server, Gateway
4.2 Service Complaint (Node.js)
* Port : 3000
* Base de données : MongoDB
* Fonctionnalités :
   * Créer, consulter, mettre à jour, supprimer une réclamation
   * Répondre en tant qu'admin
   * Marquer comme résolu
   * Filtrer par email utilisateur
* Endpoints REST : /api/complaints/, /api/complaints/:id/status, etc.
* Dépendances : Eureka, Gateway
4.3 Service User
* Port : 8081
* Nom : Yassine Sboui
* Base de données : MySQL
* Fonctionnalités :
   * Inscription / gestion des utilisateurs
   * Rôles et permissions via Keycloak
   * JWT pour la sécurité
* Dépendances : Eureka, Config Server, Gateway
4.4 Service GestionLivres (Book)
* Port : 8095
* Nom : Chaime Riahi
* Base de données : H2
* Fonctionnalités :
   * CRUD livres, tri et recherche
   * Promotions sur les livres
   * Export PDF
   * Upload d'images
* Endpoints REST : /AjoutLivre, /deleteLivre/{id}, /LivrePdf, etc.
* Dépendances : Eureka, Config Server
4.5 Service Paiement
* Port : 8085
* Nom : Soulayma Ben dahsen
* Base de données : MySQL
* Fonctionnalités :
   * Intégration Stripe : création de sessions, réessai de paiements
   * Mise à jour de statuts, suppression
   * Génération de factures PDF
   * Recherche, tri, listing des paiements
* Dépendances : Stripe, PDFBox, Feign, Gmail SMTP, Eureka, Gateway
4.6 API Gateway
* Port : 8083
* Type : Spring Cloud Gateway
* Fonctionnalités :
   * Point d'entrée unique
   * Routage dynamique via Eureka
   * Sécurisé avec Keycloak
4.7 Eureka Server
* Port : 8761
* Fonctionnalités :
   * Découverte des services
   * Enregistrement automatique au démarrage


4.8 Config Server
* Port : 8888
* Fonctionnalités :
   * Centralisation des fichiers application.yml
   * Chargement depuis un répertoire local config/
4.9 Keycloak
* Port : 8084
* Base de données : PostgreSQL
* Fonctionnalités :
   * Authentification centralisée
   * Gestion des utilisateurs et des rôles
   * Génération de tokens JWT
